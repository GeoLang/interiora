🏢 Interiora

Indoor mapping and navigation SDK — venue modelling, wayfinding, and fingerprint positioning over caller-supplied signal readings.

Features

🏗️ Venue Modelling

Venues, floors, units, openings, amenities. 12 unit categories, floor ordinal sorting, anchor coordinates.

🗺️ Indoor Graph

Connectivity graph with typed traversals — walk, elevator, stairs, escalator. Bidirectional edges, nearest-node search.

🚀 Dijkstra Routing

Shortest-path wayfinding with accessibility mode. One instruction per segment, without bearings or left/right turns.

📡 Fingerprint Positioning

k-NN matching over a caller-supplied map of signal identifier to RSSI, with no BLE or WiFi code of its own. The reported accuracy is the spread of the chosen survey points, not a validated error bound, and confidence is an unlabelled 0-1 curve.

♿ Accessibility

Wheelchair routing skips stairs and escalators over the HTTP server, whose loader marks those edges inaccessible. interiora-core on its own marks every edge accessible.

🏠 Multi-Floor

Full multi-floor support with floor changes via elevators, stairs, or escalators. Navigation instructions per segment.

Limits

Floor GeoJSON carries no rotation term, so a plan drawn on a rotated axis comes out rotated on the map.

HTTP API

The interiora-server crate serves the core over HTTP. A client posts one document per venue, containing the venue, an optional navigation graph, and optional fingerprints, then reads floors, routes, and positions back out of it. Graph edges in the document are index pairs into its own node list. The repository carries a ready document at examples/venue-demo.json.

POST /venues/{id}/routeany known roleA LineString, distance, walk time, per-segment instructions, and the floor of every vertex. Endpoints are {lon, lat, floor} and mode is default or accessible.
POST /venues/{id}/positionany known roleLocal position, floor, accuracy, confidence, and lon/lat, from a signals map of identifier to RSSI.

Floor coordinates are metres on a tangent plane at the venue anchor, with +x east and +y north. Every route except /health needs a platform JWT signed with the 32-byte-or-longer secret in PLATFORM_JWT_SECRET, and the server refuses to start without it. PORT sets the listen port, 3000 by default. Setting INTERIORA_DATA_DIR mirrors venues to that directory as JSON and reloads them at startup, otherwise they only live in memory.

Quick Start

use interiora_core::{
    IndoorGraph, IndoorNode,
    graph::{NodeKind, TraversalType},
    routing::{find_route, AccessibilityMode},
    floor_plan::Point2D,
};

let mut graph = IndoorGraph::new();
let entrance = graph.add_node(
    IndoorNode::new(Point2D::new(0.0, 0.0), 0, NodeKind::Entrance)
);
let shop = graph.add_node(
    IndoorNode::new(Point2D::new(20.0, 5.0), 0, NodeKind::Waypoint)
);
graph.add_edge(entrance, shop, TraversalType::Walk);

let route = find_route(&graph, entrance, shop, AccessibilityMode::Default)?;
println!("Distance: {:.1}m", route.total_distance);
