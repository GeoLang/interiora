🏢 Interiora

Indoor mapping and navigation SDK — venue modelling, wayfinding, and BLE/WiFi positioning.

Features

🏗️ Venue Modelling

Venues, floors, units, openings, amenities. 12 unit categories, floor ordinal sorting, anchor coordinates.

🗺️ Indoor Graph

Connectivity graph with typed traversals — walk, elevator, stairs, escalator. Bidirectional edges, nearest-node search.

🚀 Dijkstra Routing

Shortest-path wayfinding with accessibility mode. Wheelchair routing avoids stairs. Turn-by-turn instructions.

📡 BLE/WiFi Positioning

k-NN fingerprint matching for indoor location estimation. Signal-space distance, weighted average, confidence scoring.

♿ Accessibility

Wheelchair-accessible routing avoids stairs and escalators, preferring elevators. First-class accessibility support.

🏠 Multi-Floor

Full multi-floor support with floor changes via elevators, stairs, or escalators. Navigation instructions per segment.

Quick Start

use interiora_core::{
    IndoorGraph, IndoorNode, NodeKind, TraversalType,
    routing::{find_route, AccessibilityMode},
    floor_plan::Point2D,
};

let mut graph = IndoorGraph::new();
let entrance = graph.add_node(
    IndoorNode::new(Point2D::new(0.0, 0.0), 0, NodeKind::Entrance)
);
let shop = graph.add_node(
    IndoorNode::new(Point2D::new(20.0, 5.0), 0, NodeKind::Waypoint)
);
graph.add_edge(entrance, shop, TraversalType::Walk);

let route = find_route(&graph, entrance, shop, AccessibilityMode::Default)?;
println!("Distance: {:.1}m", route.total_distance);
